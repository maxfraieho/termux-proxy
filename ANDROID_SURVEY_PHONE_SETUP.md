# 📱 Налаштування Android-смартфона для проходження опитувань (Swiss Mobile Anti-Detect)

Посібник із налаштування фізичного смартфона **Android в Україні** для проходження швейцарських опитувань через сервер **Oracle VPS** під виглядом **нового швейцарського пристрою**.

---

## 🏗️ Архітектура рішення

```
[Android в Україні]
  │
  ├── 1. Мережа: Tailscale (доступ до Oracle 100.66.97.93)
  │
  └── 2. Браузер: Kiwi Browser (Chromium з розширеннями)
        ├── SOCKS5 Проксі: 100.66.97.93:1080 (Чоловік) або :1081 (Дружина)
        ├── Блокування WebRTC: повне відключення витоку локального/укр. IP
        ├── Підміна таймзони: Europe/Zurich (замість Europe/Kyiv)
        ├── Антидетект заліза: динамічний шум Canvas / WebGL (новий хеш)
        └── Геолокація: апаратний GPS вимкнено для сайтів
  │

```

## ⚙️ Покрокове налаштування смартфона

### Крок 1. Мережевий тунель (Tailscale)
1. Встановіть додаток **Tailscale** з Google Play.
2. Увійдіть у сімейний акаунт (`tukroschu@`).
3. Переконайтеся, що перемикач з'єднання увімкнено.
4. У списку машин знайдіть `n8n-teilscail` (`100.66.97.93`) — має бути статус онлайн.

---

### Крок 2. Браузер та безпека датчиків
1. Встановіть **Kiwi Browser** (з Google Play або GitHub).
2. Запустіть Kiwi і заблокуйте витік GPS:
   - Відкрийте меню (три крапки) ➔ **Налаштування** (Settings).
   - Перейдіть у **Налаштування сайтів** (Site settings) ➔ **Геолокація** (Location).
   - Встановіть перемикач у положення **Заблоковано** (Blocked).

---

### Крок 3. Встановлення розширень маскування
У Kiwi Browser відкрийте [chromewebstore.google.com](https://chromewebstore.google.com) та встановіть 4 розширення:

#### 1. ZeroOmega (або Proxy SwitchyOmega)
*Призначення: скерування трафіку браузера через Oracle.*
- Відкрийте налаштування розширення.
- Створіть профіль `Swiss_Husband`:
  - Протокол: `SOCKS5`
  - Сервер: `100.66.97.93`
  - Порт: `1080`
- (Опціонально) Створіть профіль `Swiss_Wife`:
  - Протокол: `SOCKS5`
  - Сервер: `100.66.97.93`
  - Порт: `1081`
- Увімкніть відповідний профіль у меню розширення.

#### 2. WebRTC Control
*Призначення: блокування витоку реальної IP-адреси через STUN/TURN запити.*
- У меню розширення виберіть режим: **Disable WebRTC completely** (синє коло або повне блокування).

#### 3. Change Timezone (або Spoof Timezone)
*Призначення: виправлення невідповідності між часом України та Швейцарії.*
- У налаштуваннях розширення вкажіть таймзону: `Europe/Zurich`.

#### 4. Fingerprint Defender (Canvas & WebGL)
*Призначення: емуляція «нового пристрою» (рандомізація відбитка заліза).*
- Встановіть:
  - **Canvas Fingerprint Defender**
  - **WebGL Fingerprint Defender**
- Розширення працюють автоматично: вони підмішують мікрошум у виклики рендерингу, генеруючи **новий унікальний хеш пристрою** на кожну сторінку.

## 🚀 Регламент роботи: «Сесія як з нового смартфона»

Перед кожним проходженням опитування:

1. **Увімкніть Tailscale** на телефоні.
2. **Відкрийте вкладку Інкогніто** в Kiwi Browser:
   - *Меню (три крапки) ➔ Нова вкладка інкогніто.*
   - *(У налаштуваннях розширень Kiwi увімкніть тумблер «Дозволити в режимі інкогніто» для всіх 4 розширень).*
3. **Передполітний чекап (10 секунд):**
   - Відкрийте `https://ipinfo.io/json`:
     - `country` має бути `"CH"`.
     - `org` має бути `Swisscom` (або швейцарський провайдер).
   - Відкрийте `https://browserleaks.com/webrtc`:
     - WebRTC має бути відключено або показувати тільки швейцарський IP.
4. **Пройдіть опитування.**
5. **Завершення:**
   - Закрийте вкладку інкогніто. Усі cookies, сесійні ключі та локальні сховища знищуються без сліду.

## 👥 Розподіл між Чоловіком та Дружиною

- **Чоловік (Persona A)**: у ZeroOmega активний профіль `100.66.97.93:1080`.
- **Дружина (Persona B)**: у ZeroOmega активний профіль `100.66.97.93:1081`.

Якщо обоє користуються одним смартфоном:
- Рекомендується використовувати **два різні браузери** (наприклад, Kiwi для Чоловіка, а Firefox із плагінами для Дружини).
- Або використовувати додаток **Shelter** (створює ізольований Android Work Profile з окремою незалежною копією Kiwi).
