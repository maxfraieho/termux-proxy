# 🛡️ Повний посібник: Проходження опитувань удвох з одного ноутбука без блокувань (Dual Persona Setup)

Цей документ описує архітектуру та правила проходження швейцарських опитувань (Meinungsplatz, Qualtrics, Cint, Dynata тощо) двома різними людьми (Чоловік та Дружина) з **одного фізичного ноутбука**.

---

## 🎯 Чому виникають блокування (Вектори антифрод-виявлення)

Антифрод-системи платформ опитувань (ThreatMetrix, FingerprintJS Pro, DataDome) аналізують такі фактори:
1. **Зовнішня IP-адреса та підмережа**:
   - Якщо 2 акаунти проходять однакове опитування з одного IP або одного провайдера в один і той самий час — опитування дискваліфікується ("Ви або хтось з вашого домогосподарства вже пройшли це опитування"), або акаунти баняться.
2. **Апаратний цифровий відбиток (Hardware Fingerprint)**:
   - WebGL / GPU Renderer, Canvas hash, AudioContext, CPU cores (`hardwareConcurrency`), RAM (`deviceMemory`).
   - Якщо два акаунти мають різні cookies, але однаковий Canvas/WebGL відбиток ноутбука — система склеює їх в один профіль.
3. **Витоки WebRTC**:
   - Браузер може видати локальний IP або справжній український IP через WebRTC STUN/TURN запити повз проксі.
4. **Невідповідність геолокації та системи**:
   - Швейцарський IP + нешвейцарська таймзона (`Europe/Kyiv` замість `Europe/Zurich`) або відсутність `de-CH` / `fr-CH` у заголовках.

## 🚀 Як запускати на ноутбуці

У папці `laptop_client/` створено готові лаунчери для кожної платформи:

### 🐧 Для Linux:
```bash
# Чоловік:
./laptop_client/Launch_Persona_A_Husband.sh

# Дружина:
./laptop_client/Launch_Persona_B_Wife.sh
```

### 🪟 Для Windows:
- Двічі клікніть `Launch_Persona_A_Husband.bat` або `Launch_Persona_B_Wife.bat`.

### 🍎 Для macOS:
- Запустіть `Launch_Persona_A_Husband.command` або `Launch_Persona_B_Wife.command`.

## 🌟 Альтернатива: Налаштування в Антидетект-браузері (Dolphin{anty} / AdsPower / Octo)

Якщо ви використовуєте професійний антидетект-браузер:

### Профіль 1 (Чоловік):
- **Назва**: `Swiss_Persona_A`
- **Проксі**: `SOCKS5` -> Host: `100.66.97.93`, Port: `1080` (без логіну/паролю)
- **Операційна система**: Windows
- **User-Agent**: Chrome (версія 124+)
- **Timezone**: `Based on IP` (або вручну `Europe/Zurich`)
- **WebRTC**: `Altered` або `Disabled`
- **Canvas / WebGL / Audio**: `Noise` (додати шум)
- **Мова**: `de-CH,de,en`

### Профіль 2 (Дружина):
- **Назва**: `Swiss_Persona_B`
- **Проксі**: `SOCKS5` -> Host: `100.66.97.93`, Port: `1081`
- **Операційна система**: Windows (або macOS)
- **User-Agent**: Firefox або Chrome іншої версії
- **Timezone**: `Based on IP` (`Europe/Zurich`)
- **WebRTC**: `Altered` або `Disabled`
- **Canvas / WebGL / Audio**: `Noise` (новий унікальний хеш)
- **Мова**: `de-CH,fr-CH,en`

## 📋 5 Золотих правил роботи без банів

1. **Ніколи не перетинати профілі**:
   - Чоловік завжди заходить ТІЛЬКИ через Профіль A (Порт 1080).
   - Дружина завжди заходить ТІЛЬКИ через Профіль B (Порт 1081).
2. **Різні IP-адреси для двох пристроїв**:
   - Переконайтеся, що Android 1 та Android 2 підключені до різних мереж (наприклад, один на домашньому швейцарському Wi-Fi, другий на швейцарській SIM-карті / іншій точці).
3. **Якщо доступний лише 1 Android-пристрій одночасно**:
   - Не проходьте одне й те саме опитування одночасно.
   - Перед переходом між акаунтами зробіть ротацію IP на телефоні (увімкнути/вимкнути Авіарежим на 10 сек) та зробіть паузу 15-30 хвилин.
4. **Перевірка перед кожною сесією**:
   - Відкрийте в браузері `https://ipinfo.io/json` або `https://browserleaks.com/webrtc`.
   - Перевірте: `country == "CH"`, WebRTC не видає реальний IP, таймзона `Europe/Zurich`.
5. **Очищення та роздільність кешу**:
   - Обидва профілі мають ізольовані каталоги даних і ніколи не діляться cookies чи локальним сховищем.
