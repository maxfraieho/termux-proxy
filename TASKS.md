# 📋 Task Status: Policy Routing Implementation for Swiss Proxy

**Status:** COMPLETED ✅  
**Architecture:** Linux Kernel Policy Routing (Selective Exit Node Routing via `uidrange`)

## 🎯 Architecture Summary

Routes outgoing traffic generated by `smart_proxy.py` (running as dedicated user `swissproxy`, UID 998) through the Swiss Tablet (`100.100.74.9`, Tab S8 Ultra) Tailscale exit node **WITHOUT** altering the default route of the Oracle server:
- `n8n`, `Docker`, `PostgreSQL`, `Telegram Bot`, and `SSH` remain completely direct via `ens3` (Oracle Cloud / Germany).
- Tailnet access (`100.64.0.0/10`) is preserved for all system users and processes.
- Termux and microsocks dependencies on Android devices have been fully removed.

```
[Laptop Browser / Client]
    │ HTTP :8888 / :8889, SOCKS5 :1080 / :1081
    ▼
[Oracle Server — smart_proxy.py (User: swissproxy, UID 998)]
    • Injects Swiss headers (User-Agent Chrome/Firefox, Accept-Language de-CH/fr-CH)
    • Strips tracking headers
    │
[Linux Kernel Policy Routing Engine]
    ├─ Rule 5265: from all to 100.64.0.0/10 lookup 52 (Tailnet peers reachable by everyone)
    ├─ Rule 5268: not from all uidrange 998-998 lookup main (Direct Oracle internet for all other apps)
    └─ Rule 5270: from all lookup 52 (Exit Node default route in table 52, only reached by UID 998)
    │
    ▼
[Swiss Tablet 100.100.74.9 — Tailscale Exit Node]
    Swisscom Residential Network ➔ Valais / Zürich Exit IP 🇨🇭 (188.61.140.21)
```

## 🛠️ Implemented Components

1. **`smart_proxy.py`**:
   - Both Husband (Channel A) and Wife (Channel B) use `upstream: "direct"`.
   - Outbound sockets created by `swissproxy` (UID 998) are routed by kernel rule 5270 to table 52.

2. **`/etc/systemd/system/swiss-proxy.service`**:
   - `ExecStartPre` automatically installs policy rules 5265 and 5268 on service startup.

3. **`watchdog.sh`**:
   - Maintains Tailscale exit node `100.100.74.9`.
   - `ensure_isolated_policy_routing` automatically re-applies isolation rules.
   - Tests exit node health via `sudo -u swissproxy curl http://checkip.amazonaws.com/`.

4. **`telegram_bot.py` & `recover_system.sh`**:
   - Fully synced with policy routing rules.
