## 🎯 Architecture Goal

Route outgoing traffic generated by `smart_proxy.py` through the Swiss Tablet (`100.100.74.9`) Tailscale exit node **WITHOUT** altering the default route (`0.0.0.0/0`) of the Oracle server (so `n8n`, `PostgreSQL`, `Telegram Bot`, and `SSH` remain completely direct via `eth0`).

```
[Laptop Browser]
    │ HTTP :8888 / SOCKS5 :1080
    ▼
[Oracle Server — smart_proxy.py (User: swissproxy)]
    • Injects Swiss headers (User-Agent Chrome 124, Accept-Language de-CH)
    • Strips tracking headers
    │
    │ Outgoing TCP marked with iptables (mark 0x5779)
    ▼
[Linux Kernel Policy Routing — table 200]
    fwmark 0x5779 ➔ table 200 ➔ dev tailscale0 via 100.100.74.9
    │
    ▼
[Swiss Tablet 100.100.74.9 — Tailscale Exit Node]
    Swiss VPN ➔ Zürich Exit IP 🇨🇭
```

## 🛠️ Execution Checklist (Run when tablet is ONLINE)

### Step 1: Create dedicated Linux user on Oracle
```bash
sudo useradd -r -s /bin/false swissproxy
```

### Step 2: Update `/etc/systemd/system/swiss-proxy.service`
```ini
[Unit]
Description=Swiss Fingerprint Proxy v3.0 (Policy Routing via Exit Node)
After=network.target tailscaled.service
Wants=tailscaled.service

[Service]
Type=simple
User=swissproxy
Group=swissproxy
WorkingDirectory=/home/ubuntu/termux-proxy/oracle
ExecStartPre=+/sbin/iptables -t mangle -A OUTPUT -m owner --uid-owner swissproxy -j MARK --set-mark 0x5779
ExecStartPre=+/sbin/ip rule add fwmark 0x5779 table 200
ExecStartPre=+/sbin/ip route add default dev tailscale0 via 100.100.74.9 table 200
ExecStart=/usr/bin/python3 -u smart_proxy.py
ExecStopPost=+/sbin/iptables -t mangle -D OUTPUT -m owner --uid-owner swissproxy -j MARK --set-mark 0x5779
ExecStopPost=+/sbin/ip rule del fwmark 0x5779 table 200
ExecStopPost=+/sbin/ip route flush table 200
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### Step 3: Grant directory permissions
```bash
sudo chown -R swissproxy:swissproxy /home/ubuntu/termux-proxy/oracle
sudo chmod 755 /home/ubuntu/termux-proxy/oracle
```

### Step 4: Apply & Test
```bash
sudo systemctl daemon-reload
sudo systemctl restart swiss-proxy.service

# Test routing from proxy:
curl -x http://100.66.97.93:8888 https://ipinfo.io/json
# Expected: "country": "CH"

# Test direct routing from n8n / system (should remain Ukraine/Oracle IP):
curl https://ipinfo.io/json
```
